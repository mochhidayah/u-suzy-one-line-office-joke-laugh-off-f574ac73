A tiny Node program that writes one original one-line office joke to
`/output/entry.txt` for the make.fun bounty
`u-suzy-one-line-office-joke-laugh-off-f574ac73`.

The joke:

> My boss said AI will replace us all, so I taught it to ask for a raise first.

## Run

```sh
node main.ts
```

`main.ts` builds the line from `joke.ts`, checks it with `guard.ts`
(single line, 1–200 chars, about office life), then writes it to
`/output/entry.txt`.
